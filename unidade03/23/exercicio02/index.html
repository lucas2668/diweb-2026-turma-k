Trabalhando com tabelas e seus atributos

Podemos usar classes, ids e estilos inline para formatar as tabelas, suas linhas e células. A classe é definida usando o atributo class, o id é definido usando o atributo id, e os estilos inline são definidos usando o atributo style

Usando tags semânticas, podemos criar uma tabela para exibir informações sobre nossos animais de estimação, como nome, idade e raça. A tabela pode ser formatada usando CSS para torná-la mais atraente visualmente. As tags thead, tbody e tfoot podem ser usadas para organizar o conteúdo da tabela em seções distintas. A tag thead é usada para definir o cabeçalho da tabela, a tag tbody é usada para definir o corpo da tabela, e a tag tfoot é usada para definir o rodapé da tabela. Elas não são obrigatórias, mas podem ajudar a tornar a tabela mais fácil de ler e entender.
